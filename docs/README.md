## Generated report

[reports/us101_replica/report.md](reports/us101_replica/report.md) — the
auto-generated calibration/validation report (`validation.report`,
CLAUDE.md §7.4) for the 20-replicate with-boundary US-101 run set: criteria
table with pass/fail, per-replicate speed contours, seeds, config hashes,
and calibration provenance. This artifact — a report a reviewer can rerun —
is the product feature the validation stack exists to serve.

## Demo corridor gallery

[gallery/](gallery/README.md) — two real corridors (I-24 Nashville, US-75
Dallas) onboarded via the `osm_generic` OSM pipeline and simulated with the
calibrated fleet. Demonstrates onboarding speed, explicitly not corridor
validity.
