# Code audit, 2026-09-03 (follow-up list)

Ten independent read-only audit lenses ran over the repository on 2026-09-03 (controllers, macrosim, microsim, validation, calibration, api+frontend, tests+CI, docs numbers, spec gaps, typing/quality), each asked for file:line evidence and a proposed fix. Adversarial verification (three verifiers per finding) completed only for the api+frontend lens before an API session limit cut the run off, so everything below the first section is **unverified finder output**: re-check each item against the code before acting on it. Nothing in this list has been fixed yet; the document exists so the findings are not lost.

Counts: 113 findings from 10 finder agents.

## Verified (api+frontend, 3 of 3 verifiers confirmed)

Fix: retype to the `MetricsOut` shape, read `metrics.replicates.map(r => r.metrics[k])`, make `AggregateStat` fields nullable, update the mock, add a test against a real-API fixture.

### Finder 4 (7)

- `packages/macrosim/macrosim/runner.py:345` (high, numerical-physics / positive-feedback ratchet) — The seeded perturbation re-derives its flux cap every step from the density of the very cell the cap congests, so any binding perturbation ratchets to cap=0 and becomes a full road closure (rho_jam, zero flux) for its whole duration instead of a v_drop slowdown.
  Proposed fix: Freeze the reference speed at onset: on the first step with pert.t_s <= t, compute v_prevail once from the pre-perturbation density (or from the upstream demand state, e.g. V_e at the inflow's free-flow density), store it, and hold `cap = capacity_at_speed(fd, max(v_prevail_onset - v_drop_ms, 0))` constant for the window. - `tests/test_macrosim/test_macrosim_v1_legacy.py:88` (medium, test passes for the wrong reason / unvalidated claim) — test_v1_seeded_jam_dissipates_on_ring asserts a >=50% amplitude decay and attributes it to 'LWR dissipation', but the IC lies entirely on the congested (linear) branch where the exact LWR solution is pure translation at w with zero decay; the decay is 100% grid-dependent numerical diffusion and the assertion fails on a finer grid.
  Proposed fix: Rewrite the docstring to state the truth (congested-branch bump = linear advection; observed decay is numerical diffusion of first-order Godunov at Courant 0.18) and turn the test into a discretization regression: assert the peak position moves at w (x_peak(t) ≈ x0 + w*t on the ring) and that the amplitude ratio increases monotonically under grid refinement (e.g. ratio(n=400) > ratio(n=100)).
